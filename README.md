# IST Clock — Android APK

A simple Android app showing live India Standard Time (IST / UTC+5:30) with selectable visual themes.

## Build APK on GitHub

1. Create a new GitHub repository.
2. Upload all files in this project to the repository.
3. Open **Actions** and select **Build IST Clock APK**.
4. Run the workflow with **Run workflow**, or push a commit.
5. Open the completed workflow run and download the **IST-Clock-debug-apk** artifact.

The project uses Android Gradle Plugin 8.5.2, Kotlin 2.0.20, and Gradle 8.7.
